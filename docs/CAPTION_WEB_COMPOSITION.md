# Accepted captions in the exhibition lifecycle

The web source reader supports the original v2 caption agreement and the separately agreed v3 Deepgram review agreement. Existing contracts and artifacts keep their original capability, files, source identities and authority deadlines. A v3 review agreement is not automatic six-language alignment qualification.

For v3 captions, downstream web work requires the exact accepted correction edition. A saved draft, automatic source review or a listening statement alone cannot supply that acceptance, even when other web inputs may use explicitly reviewed drafts. Every original recording must have a complete attributed review revision, the correction agreement must identify that exact revision set, independent checks must verify the original recording and effective VTT, and an owner or judge must separately accept the artifact with the six language limitations acknowledged. A system operator cannot make the listening or curator decision.

The reader checks the immutable original recognition, its signed raw response, the complete source and audio hashes, the append-only review ancestry and the actual author's role at the declaration time. Uncertain, unheard or missing boundaries stay untimed. Earlier drafts and automatic failures remain available through their original evidence and revision downloads. A later annotation does not rewrite an already agreed and accepted edition.

When one operation inspects all 78 tracks, it validates the complete original artifact once for that operation and checks each signed recognition receipt and revision ancestry using the caller's transaction client. This reader is never shared across requests, leases or authority checks. Deepgram supplies recognition and word timing; narration generation retains its separate Gemini provenance.

Each web label keeps its original recognition receipt and a versioned fingerprint of the effective timing provenance. That fingerprint binds the accepted caption artifact, original and assembly jobs, correction agreement, exact review revision, original automatic candidate, complete source and effective cues. VTT media metadata and downloaded bytes must match those same cues. The web acceptance pack, producing worker, every browser request, portable file manifest, preview and publication then bind the resulting exact source digest. A different accepted edition needs its own source agreement and checks; it cannot borrow an earlier job or browser report.

Publication retains the full private caption provenance alongside the six independent artifact acceptances. Public reader files retain the compatible qualified source schema, caption ancestor hash, effective timing/cue hashes and exact VTT register. Private reviewer names and raw recognition bodies are not copied into a public reader. Clearly marked synthetic fixture decisions produce explicit synthetic provenance in the public source record; they are never evidence of a person listening or accepting real speech.

The original caption authority ceiling also limits web work. Workspace continuation, a new signed Passport or a later annotation does not extend that ceiling. Reading original evidence and collecting an already dispatched hosted result remain separate from authority for new work. Original-result recovery retains the existing same-tenant owner/judge/operator policy and never starts a replacement recognition or browser run.

# Keyboard and asynchronous review

The shared native dialog explicitly wraps Tab and Shift-Tab across the current visible, enabled controls. It recomputes that set when keys are pressed, excludes hidden/inert/disabled controls and closed detail contents, handles dynamically removed controls and focus loss, and keeps an empty dialog focusable. Native cancel is prevented so the caller's busy-close rule remains authoritative. Ordinary callers retain their captured opener; asynchronous publication captures its trigger before the request and resolves an explicit enabled fallback at close time.

Caption saves claim one in-flight identity, preserve an unchanged unknown request for retry, reject a response for another artifact/track/request, and ignore late responses after the editor changes scope. A stale revision returns409 and requires an explicit saved-history refresh. Saving and unsaved edits guard track, view, commission, browser-history and Home navigation. The listening dialog stays open during a pending save and returns to a readable heading when its former trigger becomes disabled after confirmation.

Opening a native browser report moves focus from the removed loading trigger through the read status to the first original state heading. A completed read does not move focus after the user has continued elsewhere. Failed and mismatched original reads remain errors, with a retry of the same original case.
