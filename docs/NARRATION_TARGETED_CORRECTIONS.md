# Targeted narration repair

The targeted agreement replaces only the exact failed recordings named in the latest independent report. Every passing recording keeps its original bytes, producing job, contract, speech receipt and media object. The assembled collection receives a new manifest and a complete independent check. It does not claim that preserved recordings were produced again.

`quill.targeted-correction.v1` is separate from the earlier `quill.additional-correction.v1` policy. The earlier policy still permits one complete Arabic pacing correction and rejects other failure scopes. Its signed terms, exhausted allowance, submissions and results remain unchanged. The targeted policy applies after that separately agreed complete round has finished and been checked. It permits at most five Arabic duration or English provider-transcript failures, with every other deterministic file check passing. Other failure scopes require another reviewed agreement.

## Exact scope and authority

The reviewed `guild.narration-targeted-correction.v1` proposal binds the latest independent evaluation and criteria report, every earlier complete submission and report, exact upstream artifacts and review identities, acceptance pack, saved correction note, provider policy, prices and original approval receipts. Its signed register names every recording as either a replacement or a carried original. Each entry records its script hash, complete segment hash, original artifact and contract, producing job, input bindings, speech receipt, original PCM hash and media object. Replacement entries additionally bind the selected cue and exact instruction hash. A changed report, source, register, price or approval requires a new review.

The agreement advances the contract version and retains an immutable amendment with the earlier contract. It releases only the exact unaccepted narration reservation across its original Passport chain. A fresh Passport must approve the new agreement before the same price can be reserved once. The narration price remains $87: $80 for work and $7 for service. The commission proposal remains $540 against its $640 ceiling, with no additional correction charge.

The earlier agreement's original signed approval and actor expiry remain an explicit authority ceiling, alongside the latest approval actor and current Passport deadlines. Workspace renewal cannot extend that frozen ceiling. Both original actors must remain active before production. The worker rechecks the current approval, source and review bindings, all retained originals, signed agreement, exact job identity, expiry and revocation before each new external speech or storage request.

The controlled service authorizes one production job and exactly one original stream for each replacement. Failed, interrupted and indeterminate attempts count. There is no candidate generation, automatic retry after failure or second production identity. Completed parts and original partial streams remain inspectable; the next attempt requires the next explicit scope review. An unknown earlier stream, ongoing work, checkout, dependent production or accepted work prevents this agreement.

The HMAC receipt attests to Guild's team-operated Quill & Echo offer. It is not an independent provider-owner signature, A2A negotiation, AP2 mandate, human listening approval or PayPal consent.

## Delivery choice and unchanged measurements

Development calibration compared two cues on the five failed source scripts: ten requests, no automatic retries. Each arm passed four of five measured cases. The reviewed selection uses the duration cue only for `ar/loc-det-4a12861`, the original 165–175 words-per-minute Arabic cue for the other Arabic replacements, and the original English cue. All ten development outcomes remain retained privately, including both failures. The selected combination passed five observed development cases; this is a disclosed retrospective selection, not a prospective success guarantee. Development audio is excluded from commissioned work.

The selected instruction strings match the frozen development inputs exactly. The duration cue uses the unchanged per-script target seconds and brief natural pauses. The full source script must be spoken once, without additions or omissions. Model and voice remain `gpt-realtime-2.1` and Marin, with synthesis speed 1. The only local tempo treatment remains 0.85–1.20×. The implementation does not stack provider speed with local tempo to evade that limit.

The original duration estimates, ±10% tolerance, mono 24 kHz / 96 kb/s MP3, −18…−14 LUFS, true peak ≤−1 dBTP, zero clipping and exact normalized provider transcript remain unchanged. There is no silence padding, script truncation, transcript editing or relaxed tolerance. Blind recognition remains advisory; it cannot establish listening quality, naturalness or fluent acceptance.

## Mixed provenance and independent verification

Earlier artifacts and reports retain their strict `guild.narration.v2` and `guild.narration-verification.v2` schemas. A targeted assembly uses `guild.narration.v3`; the producer copies carried segments unchanged and creates new media only for the registered replacements. Per-file lineage explicitly distinguishes the new assembly from the old production identities. Private downloads and historical evidence exports continue to include the original agreements and reports.

`guild.narration-verification.v3` validates the signed replacement/carry-forward register and new assembly job, then retrieves and decodes all files. For each carried file it verifies the original contract, input bindings, job, receipt and media metadata. For each replacement it verifies the new job and contract, unique new stream and media identities, and exact reviewed instructions. It reconstructs the frozen audio transform from each complete original PCM stream and compares it with independently retrieved MP3 bytes. Blind recognition reads each file under the new verification, while earlier recognition reports remain unchanged.

For the current 78-recording scope this means five new recordings, 73 preserved originals and 78 independent file checks. Failed measurements remain failures. Human listening, fluent review, exact upstream acceptance and payment remain separate gates.
